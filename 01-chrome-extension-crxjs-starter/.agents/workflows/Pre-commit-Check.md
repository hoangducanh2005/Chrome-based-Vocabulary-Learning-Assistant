---
description: Kiểm tra code trước khi commit để đảm bảo chất lượng.
---

1. Kiểm tra toàn bộ file đang thay đổi, tìm lỗi syntax hoặc logic rõ ràng. 
2. Đảm bảo không có console.log, debug code, hoặc hardcoded credentials nào 
còn sót. 
3. Kiểm tra các hàm mới có comment/JSDoc chưa. Nếu chưa, tự động thêm vào. 
4. Tóm tắt những thay đổi thành một đoạn commit message ngắn gọn theo 
chuẩn Conventional Commits.
