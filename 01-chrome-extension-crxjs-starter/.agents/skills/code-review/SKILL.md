# Code Review Skill 
Khi review code, thực hiện theo các bước sau: 
## Danh sách kiểm tra 
1. Tính đúng đắn: Code có làm đúng yêu cầu không? 
2. Edge cases: Các trường hợp lỗi có được xử lý không? 
3. Style: Code có theo convention của dự án không? 
4. Hiệu suất: Có điểm nào rõ ràng kém hiệu quả không? 
## Cách trình bày phản hồi - Nêu cụ thể cần thay đổi chỗ nào - Giải thích tại sao, không chỉ nói cái gì - Gợi ý cách thay thế khi có thể
