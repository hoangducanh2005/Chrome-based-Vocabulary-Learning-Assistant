# Chrome-based Vocabulary Learning Assistant

A powerful Chrome extension built for language learners. It helps you learn and retain vocabulary seamlessly while reading foreign language content online without interrupting your reading flow.

## 🚀 Features (MVP)

* **Instant In-Page Translation:** Highlight any word or phrase to see a lightweight, non-blocking tooltip with its translation.
* **Contextual Vocabulary Saving:** One-click save from the translation tooltip. Automatically captures the highlighted word, translation, source URL, and surrounding context sentence.
* **Flashcard Review Module:** A built-in SRS (Spaced Repetition System) interface accessible via the extension popup to review saved words.
* **Daily Statistics Dashboard:** Track your learning progress directly in the popup, including words saved today, words reviewed, and your learning streak.
* **AI-Powered Passage Summarization:** Highlight long passages of text and right-click to get an AI-generated bulleted summary.

## 🛠 Tech Stack

* **Platform:** Chrome Extension Manifest V3 (MV3)
* **UI Framework:** React (Popup and Content Script UI)
* **Language:** TypeScript
* **Bundler:** Vite + CRXJS Vite Plugin
* **Testing:** Vitest + React Testing Library + MSW

## 📁 Architecture

The project strictly follows a **Feature-Based Architecture**. Code is grouped by domain/feature rather than technical type:

* `src/features/` - Core product features (`translation`, `vocabulary`, `flashcards`, `stats`, `settings`).
* `src/core/` - Global setup, service worker entry (`background.ts`), and central message routing.
* `src/shared/` - Reusable components, hooks, utilities, and typed `chrome.storage` wrappers.
* `src/popup/` - Extension popup entry and routing.
* `src/content/` - Content script entry and shadow DOM UI injector.

## 📦 Quick Start

### 1. Install dependencies

```bash
npm install
```

### 2. Start development server

```bash
npm run dev
```

### 3. Load the extension in Chrome

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable **Developer mode** in the top right corner.
3. Click **Load unpacked** and select the `dist` folder generated by the dev server.

### 4. Build for production

```bash
npm run build
```

### 5. Run tests

```bash
npm run test
npm run test:ui
```
